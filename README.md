# Мои папки для Lampa

Плагин создаёт пользовательские папки в разделе избранного Lampa. Совместимость: Lampa 3.3.2, Android-клиент 1.12.10-566.

## Установка

В Lampa откройте **Настройки → Расширения → Добавить плагин** и вставьте:

```
https://cdn.jsdelivr.net/gh/yakovalexan7-ship-it/lampa-my-folders@main/tv.js
```

После добавления полностью перезапустите Lampa.

## Использование

- В разделе **Избранное → Мои папки** выберите **＋ Создать папку**.
- На странице фильма или сериала нажмите **В мои папки**.
- Переименование и удаление доступны через **Управление папками**.

Данные хранятся локально на устройстве и не изменяют обычное избранное.
